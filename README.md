🏥 Hospital Bed Management System

A student project demonstrating a web-based interface for managing hospital beds and basic patient admission records.

🌐 Live Demo

"Open Hospital Bed Management" (https://arindamchakraborty179-glitch.github.io/Hospital-Bed-Arrangement-/)

📌 Project Overview

This project provides a simple interface to explore hospital bed availability and manage demo patient records. It is intended for learning and demonstration purposes.

✨ Features

- 🔐 Demo login interface
- 🛏️ 20-bed visual map
- 🏥 Patient admission and discharge
- 📊 Free and occupied bed statistics
- 📋 Demo patient records
- 📁 CSV export
- 💾 Browser local storage

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Python component included in the repository

🚀 Getting Started

Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.

For the intended web interface, ensure "index.html", "style.css", and "app.js" remain in the same directory.

GitHub Pages

The website can be hosted using GitHub Pages.

1. Open the repository's Settings.
2. Select Pages.
3. Choose the "main" branch and "/ (root)" folder.
4. Save the settings and wait for deployment.

This is a student/demo project, not a production hospital management system.
